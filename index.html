O que vem no ZIP

Módulos reais. Ative o que precisa.

Não é um HTML salvo com Ctrl+S. É um pacote limpo que dá pra ler, editar e mandar pra IA.

  • HTML estruturado — DOM serializado limpo em index.html
  • CSS + estilos inline — folhas, <style> e style=""
  • Scripts JS — externos e inline da página
  • Selecionar elemento — capture só o bloco que importa
  • Imagens, fontes, mídia e arquivos referenciados
  • Caminhos reescritos para pasta assets/
  • Poster, vídeos e ícones quando disponíveis
  • Pronto pra abrir offline
  • Classes Tailwind detectadas no DOM
  • meta.json com URL, título e módulos ativos
  • README com contexto pronto pra IA
  • Ideal pra Cursor, Claude Code e Lovable
  • Crawl multi-página no mesmo domínio
  • Funil completo: VSL, upsell e obrigado
  • Adaptar PLR e landings que já convertem
  • 100% local — nada sobe pra servidor
